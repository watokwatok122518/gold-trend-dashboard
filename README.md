# 🪙 Gold Trend Intelligence Dashboard

This is a lightweight web-based dashboard that provides real-time updates and filtered insights on the gold market.

## 🔍 Features

- 📈 **Live Gold-Specific News** (filtered by trend relevance)
- 🌍 **Macro & Geopolitical News** (impacting gold, e.g., from US, China, EU)
- 🧠 **AI Insights** (summary and interpretation of the market)
- 🎓 **Expert Analysis** from top traders and analysts
- ✍️ **Your Own Notes** section for custom journaling
- 📅 **Forecasts**:
  - Daily
  - Weekly
  - Monthly
- 🎯 **Sniper Entry Zones** (key technical zones for entry)
- 🕘 **Institutional Trading Sessions** (converted to your local time)
- ⚠️ **Macro Risk Level Bar**
- 🔁 Auto-refreshes every **5 minutes**
- 📆 Stores and tracks insights for **1 week**, including weekends

## 🌐 Deployment

This project is 100% static and easily hosted on:
- GitHub Pages ✅
- Netlify
- Vercel

### To deploy via GitHub Pages:

1. Upload `index.html`, `style.css`, and `script.js` to your repository.
2. Go to `Settings` → `Pages`.
3. Set the source to `main` branch and root folder (`/`).
4. Access your site at:  
   `https://<your-username>.github.io/<your-repo-name>/`
